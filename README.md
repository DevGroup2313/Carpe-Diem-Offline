## Important: this one needs to be hosted

Unlike the other builds, you cannot simply double-click `index.html` and get the
full experience. The offline installation is done by a **service worker**, and
browsers only allow service workers over `http://localhost` or `https://`, never
from a `file://` path. Opened directly from your hard drive the app still runs,
but it will not install and will not cache.

So: to try it locally, serve it. To share it, host it.

### Try it locally in one line

Open a terminal in this folder and run:

```
python3 -m http.server 8765
```

Then visit **http://127.0.0.1:8765/index.html**. Press Ctrl+C in the terminal
when you have finished.

### Host it for real

Upload the entire contents of this folder, keeping the structure intact, so that
`index.html`, `manifest.webmanifest`, `sw.js` and the `icons` folder all sit
together at the same level. Any static host will do, and several offer free
tiers suitable for this. Check current terms before committing to one.

Two rules whatever you choose:

- It must be served over **https**, or the service worker will not register.
- Keep the URL stable. Every application and essay will point at it, and a link
  that moves is worse than no link.

## Installing it as an app

**On a phone or tablet.** Open the link in the browser, then use *Add to Home
Screen*. On iPhone that is the Share button in Safari; on Android it is the menu
in Chrome. It then opens in its own window with the Carpe Diem seal as its icon,
with no browser chrome.

**On a laptop.** In Chrome or Edge an install icon appears in the address bar.
In Safari, use *File, Add to Dock*.

After the first successful load it works offline. You can turn off wifi entirely
and it still opens.

## When you publish an update

Replace the files and make sure `sw.js` carries a **new cache name**. It
currently reads:

```
const CACHE = "carpe-diem-demo-committee-v202610121051";
```

That name carries this edition and this build (1051). Changing it is what tells
every installed copy to fetch the new version instead of serving the old one from
its cache. If you forget, people who already installed it keep seeing the old
build indefinitely. Each build you receive already has this set correctly.
